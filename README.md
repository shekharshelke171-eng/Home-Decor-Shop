
# 🏡 Home Decor Shop

A modern Django-based Home Decor E-commerce Website built to provide a smooth and user-friendly online shopping experience.

## 📌 About the Project

Home Decor Shop is an e-commerce web application where users can explore home decor products, view product details, add items to their cart, manage wishlists, and place orders.

The website is designed with a warm, elegant and responsive interface.

## ✨ Features

- 🛍️ Browse Home Decor Products
- 🔍 Product Search
- 🗂️ Category-Based Product Filtering
- 📦 Product Details Page
- 🖼️ 360° Product Image View
- 🛒 Shopping Cart
- ❤️ Wishlist
- 👤 User Registration & Login
- 🚪 User Logout
- 💳 UPI Payment Reference & Screenshot Submission
- 💵 Cash on Delivery
- 📋 Order Management
- 🧾 Order Success Page
- 📄 PDF Order Receipt
- ⚙️ Django Admin Panel
- 📱 Responsive UI

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone  https://github.com/shekharshelke171-eng/Home-Decor-Shop.git

```

### 2. Navigate to Project Folder

```bash
cd Home-Decor-Shop
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run Database Migrations

```bash
python manage.py migrate
```

### 7. Start Development Server

```bash
python manage.py runserver
```

Open your browser:

http://127.0.0.1:8000/
